# Humanify

**From 100% AI to 0% AI - In Seconds**

Machines write. We humanize. Instantly convert AI text into words that sound real, meaningful, and human.

## 🚀 Features

- **Original Meaning**: Preserves your original message and intent, transforming AI text into an authentic human voice without losing context
- **Effortless Flow**: Enhances robotic AI-generated content with smooth, natural, and engaging language
- **Zero AI Detection**: Generates content with a 0% AI detection score on leading platforms
- **Free & Unlimited**: Transform up to 1,000 characters at a time, no sign-up required
- **Total Privacy**: Your content is never stored or reused to train AI models
- **Instant Results**: Get immediate, high-quality transformations in seconds

## 🛠️ Tech Stack

- **Vite** - Fast build tool and development server
- **TypeScript** - Type-safe JavaScript
- **React** - UI library
- **shadcn/ui** - Modern UI components
- **Tailwind CSS** - Utility-first CSS framework

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/humanify.git
cd humanify
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
```bash
cp .env.example .env
```

4. Add your Gemini API key to the `.env` file:
```env
VITE_GEMINI_API_KEY="your-api-key-here"
```

## 🚀 Getting Started

1. Start the development server:
```bash
npm run dev
```

2. Open your browser and navigate to `http://localhost:5173`

3. Paste your AI-generated content and watch it transform into natural, human-like text!

## 📝 How It Works

1. **Input**: Paste your AI-generated text (up to 1,000 characters)
2. **Transform**: Our advanced AI detects mechanical patterns and transforms them
3. **Output**: Get natural, engaging content that sounds genuinely human
